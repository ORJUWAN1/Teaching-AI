## 📌 Project Overview

This project uses **Google Teachable Machine** 🧠 to build an image classification model that can distinguish between **human** 👤 and **inanimate objects** 🪑.

The model is trained using image samples for two classes:

* 👤 **Human** – images containing people
* 🪑 **Inanimate** – images containing non-living objects

## ⚙️ How It Works

The model is trained using image samples uploaded to Teachable Machine 📸. After training, an image is provided as input, and the model predicts which class the image belongs to.
